# Study Signal v0.8 · Mac 음성 학습 도우미

우하단의 반투명 채팅 버블에서 **음성으로 화면 내용을 질문**하고 **화면 응시·이탈 상태**를 확인합니다. 텍스트 질문창과 ‘작은 힌트·쉽게 설명·복습 문제’ 버튼을 제거했습니다. 메뉴 막대의 눈·음성 파형 아이콘으로 설정을 엽니다.

## 실행과 사용

Mac 설치판은 `Study-Signal-0.8.0-arm64.dmg`입니다. Apple Silicon·macOS 15 이상용으로 런타임과 기본 시선 모델을 포함합니다. DMG의 앱을 Applications로 옮겨 실행하고, 메뉴 막대 아이콘 또는 ⌘,에서 API 키를 입력합니다. 설정·보정·기록은 앱 밖의 Application Support에 유지합니다. Apple 공증 전의 개발 빌드입니다. 자세한 내용은 [Mac 설치 안내](docs/macos.md)를 보세요.

아래는 소스에서 실행하는 방법입니다.

Python 3.13 이상, Node.js 22 이상이 필요합니다. `학습 보조 실행.command`를 실행하세요. 기존 `.env` 키와 설정은 유지합니다. 첫 설치는 신경망 환경과 공식 모델을 준비합니다.

```sh
npm ci --prefix overlay
npm start --prefix overlay
```

1. 우하단 버블에서 바로 질문하거나, 메뉴 막대에서 학습 설정을 엽니다. 목표와 참고 텍스트는 설정할 수 있습니다. **자료 추가**로 PDF·TXT·MD·DOCX도 넣을 수 있습니다.
2. 카메라가 준비되면 화면 가운데를 약 2초 바라봅니다. 기본 감지는 9점 위치 보정이나 학습 영역 지정 없이 시작합니다.
3. **음성·현재 화면·첨부 자료를 OpenRouter로 전송**에 체크합니다.
4. **말하기 시작** → 질문 → **말 끝내고 보내기**. 녹음 시작 때의 화면을 고정하고 전사→설명을 처리합니다. 답변은 별도 우하단 버블에 표시하고 기본으로 OS 음성으로 읽습니다.
5. 메뉴 막대의 눈 모양 아이콘 → **설정…**에서 감도·말투·음소거·모니터·질문 범위·음성 읽기·배경 불투명도를 조절합니다.

답변과 집중 이탈 알림은 작은 별도 버블로 표시하고, 자료 관리·기록·설정은 큰 창에서 엽니다. 캡처할 때 자체 버블과 설정 창은 숨깁니다.

자료는 최대 5개, 파일당 20 MB입니다. PDF는 최대 앞 40페이지, 파일별 24,000자, 전체 맥락은 30,000자까지 참고합니다. 원본 파일 대신 추출한 텍스트를 기기에 저장하며 질문할 때 화면과 함께 모델에 전달합니다. 스캔 PDF는 화면에 열어 질문하세요.

질문 범위는 기본 **선택 모니터 전체**이며 **매번 문단 선택**으로 바꿀 수 있습니다. 시선 좌표가 부정확해도 음성 질문은 독립적으로 작동합니다. 앱 닫기 버튼은 메뉴 막대로 숨기고 감지는 계속합니다. 종료는 메뉴의 **Study Signal 종료**를 사용하세요. 숨김/표시는 Cmd+Shift+Space입니다.

## 집중 상태가 보이지 않았던 원인과 변경

이전에는 정밀 시선 보정 통과와 학습 영역 지정이 모두 필요해 보정 실패 시 계속 unknown이었습니다. 기본 모드를 **UniGaze-L 시선·머리 방향을 이용한 화면 방향 감지**로 분리했습니다. 화면 응시·이탈 확인·이탈·측정 불가·휴식·질문 상태와 관측 불가 이유를 표시합니다. 이는 인지적 집중도나 딴생각을 검증한 분류기가 아닙니다.

- 8초 연속 이탈에 시각 알림, 20초에 한국어 음성 알림. 2초 복귀 시 해제, 반복 90초 제한.
- 얼굴/눈 가림·오래된 프레임·불안정한 신호·질문/답변·휴식·생각/필기 유예 때 잔소리하지 않습니다.
- 시작 기준은 현재 실행의 메모리에만 유지합니다. 자리·거리가 바뀌면 **화면 기준 다시 잡기**를 누르세요. 민감도는 초기 설정이며 실제 사람·장비별 오탐 검증은 남아 있습니다.
- 정밀 픽셀 시선은 설정의 **정밀 시선 좌표 (실험·선택)**로 이동했습니다. 9점 보정＋별도 5점 검증을 통과하면 로컬에 저장하고, 동일 환경에서는 5점 재검증으로 재사용합니다. 기본 감지나 음성 질문의 필수 조건이 아닙니다.

## Mac 권한

| 기능 | 필요한 권한 |
|---|---|
| 화면 응시·이탈 감지 | 카메라 |
| 말하기 시작/보내기 버튼 | 마이크, 화면 녹화 |
| 선택 전역 단축키 | 위 권한＋손쉬운 사용·입력 모니터링 |

전역 단축키는 선택 사항입니다. 기본 Cmd+Shift+Enter를 누르는 동안 녹음하고 놓으면 전송합니다. 버튼 방식은 두 번의 명시적 클릭으로 시작·전송하며 전역 키 훅을 쓰지 않습니다. 최대 20초가 지나거나 취소·권한 철회·키 해제 누락이면 자동 전송하지 않고 폐기합니다. 개발 실행의 macOS 권한 목록에는 Electron으로 표시될 수 있습니다. [Mac 사용 안내](docs/macos.md)

## 모델 설정

```dotenv
AI_PROVIDER=openrouter
OPENROUTER_API_KEY=여기에_키
OPENROUTER_MODEL=anthropic/claude-sonnet-5.5
STUDY_MODEL_PROVIDER=openrouter
STUDY_MODEL_ID=
STUDY_STT_MODEL=openai/whisper-large-v3-turbo
STUDY_GAZE_MODEL=unigaze_l16_joint
LAST_HOUR_TOKEN=24자_이상의_별도_랜덤_토큰
LAST_HOUR_DATA=./data
STUDY_HEART_URL=
STUDY_HEART_TOKEN=
```

전사는 OpenRouter `/audio/transcriptions`, 설명은 기존 이미지 지원 모델입니다. 사용료는 기존 OpenRouter 계정에 청구됩니다. 무음·전사 실패 때 설명 모델을 호출하지 않으며 세션당 AI 요청은 합계 20회입니다. AI를 끈 세션에서는 실제 질문을 전송하지 않습니다. Watch 수집 서버는 선택 사항이며 Watch 앱은 포함하지 않습니다. 원격 GPU·SSH·파인튜닝은 재개하지 않았습니다.

UniGaze-L 체크포인트는 첫 설치에 약 1.22GB이며 이 Mac의 Metal GPU에서 실행합니다. 공식 고정 revision과 SHA-256을 검증합니다. 모델 라이선스는 연구·비상업용입니다. [출처와 성능 범위](docs/neural-gaze.md)

## 저장과 검증

얼굴 영상·랜드마크·원시 시선·녹음·캡처·이미지 프롬프트는 기본 기록에 저장하지 않습니다. 질문할 때만 음성·동의한 화면 범위·첨부 자료의 추출 텍스트를 OpenRouter로 보냅니다. 첨부 텍스트는 앱 로컬 저장소와 세션 자료에 남으며 자료 관리에서 제거할 수 있습니다. 질문/답변 텍스트와 집계 이벤트는 `data/study`에 남습니다. 정밀 보정 계수와 환경 식별자는 앱 로컬 저장소(`data/electron-study` 아래)에 최대 8개 저장하며 설정에서 삭제할 수 있습니다. 화면 기반 답변은 파인튜닝 예시로 내보내지 않습니다.

- Node 56개 통과. Python 71개 중 69개 통과·기존 OpenAI SDK 전용 2개 제외.
- Chrome 메인 UI 17개 흐름＋버블 UI 8개 시나리오 통과, JavaScript 오류 0.
- 동결 서비스에서 실제 OpenRouter 화면＋PDF 약 4.25초, 합성 한국어 음성＋화면＋자료 약 5.46초. PDF 고유 코드와 화면 확률을 함께 확인했습니다.
- 최종 DMG 체크섬·서명과 읽기 전용 설치 이미지의 독립 API·PDF·MPS 실행을 확인했습니다. 실제 버블의 우하단 표시 및 비활성 창, 메뉴 아이콘의 1×/2× 템플릿 등록도 확인했습니다.
- 사람의 마이크·OS 캡처·전역 키 종합 시험, 정상 학습 오탐률은 남아 있습니다. [시나리오별 결과와 한계](docs/qa-v08.md)를 참고하세요.
