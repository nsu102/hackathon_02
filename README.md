# Study Signal v0.12.0 · 화면 번역과 스크래치패드

좌상단 반투명 스크래치패드에 **화면 번역·요약·메모를 모읍니다**. 말하기 버튼으로 화면 내용을 질문하고 같은 채팅창에서 답변을 확인하며 **화면 응시·이탈 상태**를 확인합니다. 텍스트 질문과 음성 질문을 작은 좌상단 채팅창에서 이어갑니다. 메뉴 막대의 파형 시그널 아이콘으로 설정을 엽니다.

## 스크래치패드로 논문 읽기

논문이나 PDF를 화면에 열고, **말하기**를 누르고 “이거 한국어로 번역해줘”라고 말한 뒤 **보내기**를 누릅니다. **알겠습니다** 안내 뒤 질문 시작 시점의 화면 번역과 핵심 요약이 좌상단 패드에 들어갑니다. “이 부분 요약해줘”도 사용할 수 있습니다. 화면에 보이는 범위만 처리하며 논문 전체를 읽었다고 가정하지 않습니다.

평소에는 좌상단의 작은 입력창과 **채팅하기·말하기** 버튼, 학습 경과 시간·심박수를 표시합니다. 질문을 입력해 보내거나 음성 녹음을 시작하면 대화가 펼쳐집니다. **접기**로 줄여도 기록은 유지되며 **대화**로 다시 열 수 있습니다. 텍스트 질문도 현재 화면과 학습 자료를 참고합니다. 파일은 학습 설정의 **파일 추가** 한 곳에서 관리합니다. [사용 방법과 검증](docs/scratchpad.md)

## 실행과 사용

Mac 설치판은 `Study-Signal-0.12.0-arm64.dmg`입니다. Apple Silicon·macOS 15 이상용으로 음성·번역용 기본 런타임을 포함하며 시선 모델과 PyTorch는 포함하지 않습니다. 기본 DMG는 약 168 MB이며 시선 기능은 나중에 선택 설치합니다. DMG의 앱을 Applications로 옮겨 실행하고, 메뉴 막대 아이콘 또는 ⌘,에서 API 키를 입력합니다. 설정·보정·기록은 앱 밖의 Application Support에 유지합니다. Apple 공증 전의 개발 빌드입니다. 자세한 내용은 [Mac 설치 안내](docs/macos.md)를 보세요.

아래는 소스에서 실행하는 방법입니다.

Python 3.13 이상, Node.js 22 이상이 필요합니다. `학습 보조 실행.command`를 실행하세요. 기존 `.env` 키와 설정은 유지합니다. 기본 실행은 가벼운 Python 환경만 준비하며 시선 모델을 자동 설치하지 않습니다. 소스 실행의 시선 기능이 필요하면 신경망 시선 설치.command를 별도로 실행합니다.

```sh
npm ci --prefix overlay
npm start --prefix overlay
```

1. 메뉴 막대에서 학습 설정을 엽니다. 목표와 참고 텍스트는 설정할 수 있습니다. **자료 추가**로 PDF·TXT·MD·DOCX도 넣을 수 있습니다.
2. 시선 감지가 필요하면 아래 추가 패키지를 먼저 설치합니다. 설치 후 카메라를 켜고 화면 가운데를 약 2초 바라봅니다. 기본 감지는 9점 위치 보정이나 학습 영역 지정 없이 시작합니다.
3. **음성·현재 화면·첨부 자료를 OpenRouter로 전송**에 체크합니다.
4. **말하기 → 질문 → 보내기**를 누릅니다. 녹음 시작 때의 선택 모니터 화면을 고정하고 전사→설명을 처리합니다. 답변과 진행 상태는 같은 채팅창에 표시합니다. **음성 읽기는 기본 꺼짐**이며 설정에서 켤 수 있습니다.
5. 메뉴 막대의 파형 시그널 아이콘 → **설정…**에서 감도·말투·음소거·모니터·음성 읽기·배경 불투명도를 조절합니다.

답변은 채팅창에 모으고 집중 이탈 알림은 우하단의 빨간 다이얼로그로 표시합니다. 다이얼로그는 채팅창·목록과 겹치지 않게 이동하며, 자료 관리·기록·설정은 큰 창에서 엽니다. 캡처할 때 자체 버블·스크래치패드·목록·설정 창은 숨깁니다.

자료는 최대 5개, 파일당 20 MB입니다. PDF는 최대 앞 40페이지, 파일별 24,000자, 전체 맥락은 30,000자까지 참고합니다. 원본 파일 대신 추출한 텍스트를 기기에 저장하며 질문할 때 화면과 함께 모델에 전달합니다. 스캔 PDF는 화면에 열어 질문하세요.

텍스트·음성 질문 모두 **선택 모니터 전체 화면을 자동 첨부**합니다. 별도 범위 선택은 없습니다. 시선 좌표가 부정확해도 음성 질문은 독립적으로 작동합니다. 앱 닫기 버튼은 메뉴 막대로 숨기고 감지는 계속합니다. 종료는 메뉴의 **Study Signal 종료**를 사용하세요. 숨김/표시는 Cmd+Shift+Space입니다.

## 시선 감지 선택 설치

음성 질문·화면 번역·스크래치패드는 추가 설치 없이 사용합니다. 시선 감지가 필요할 때만 **Study-Signal-Gaze-arm64-v1.zip**(약 1.41 GB)을 받고, 메뉴 막대 → 설정 → **시선 감지 설치…**에서 ZIP을 선택합니다. Python을 따로 설치할 필요는 없습니다. 설치 후 **감지 켜기**를 누릅니다.

설치 진행률·취소·재시도를 제공하고, 이 앱에 고정된 SHA-256으로 패키지를 확인합니다. 설치를 취소하거나 잘못된 파일을 선택해도 기존 학습 자료와 API 키는 유지합니다. 모델은 Application Support의 components/gaze-v1에 보관하며 앱 실행이나 학습 시작 때 자동 다운로드하지 않습니다. 미설치 상태에서는 카메라도 자동 시작하지 않습니다. [선택 설치와 검증](docs/optional-gaze.md)

## 집중 상태가 보이지 않았던 원인과 변경

이전에는 정밀 시선 보정 통과와 학습 영역 지정이 모두 필요해 보정 실패 시 계속 unknown이었습니다. 기본 모드를 **UniGaze-L 시선·머리 방향을 이용한 화면 방향 감지**로 분리했습니다. 화면 응시·이탈 확인·이탈·측정 불가·휴식·질문 상태와 관측 불가 이유를 표시합니다. 이는 인지적 집중도나 딴생각을 검증한 분류기가 아닙니다.

- 8초 연속 이탈에 빨간 시각 알림, 잔소리 음소거를 직접 해제한 경우 20초에 한국어 음성 알림. 2초 복귀 시 해제, 반복 90초 제한.
- 얼굴/눈 가림·오래된 프레임·불안정한 신호·질문/답변·휴식·생각/필기 유예 때 잔소리하지 않습니다.
- 시작 기준은 현재 실행의 메모리에만 유지합니다. 자리·거리가 바뀌면 **화면 기준 다시 잡기**를 누르세요. 민감도는 초기 설정이며 실제 사람·장비별 오탐 검증은 남아 있습니다.
- 점 따라가기·보정·검증·화면 시선 점·정밀 영역 선택 UI를 제거했습니다. 기본 감지는 화면 방향만 사용하고 과거 정밀 영역 설정을 적용하지 않습니다. [간소화한 학습 흐름](docs/simple-study.md)

## Mac 권한

| 기능 | 필요한 권한 |
|---|---|
| 화면 응시·이탈 감지 | 카메라 |
| 클릭 음성 질문 | 마이크, 화면 녹화 |
| 텍스트 화면 질문 | 화면 녹화 |

대기 중 경고 다이얼로그는 표시하지 않습니다. 음성 전역 단축키는 제거했습니다. **말하기**로 녹음을 시작하고 **보내기**로 전송합니다. 최대 20초가 지나거나 취소·권한 철회가 발생하면 자동 전송하지 않고 폐기합니다. 개발 실행의 macOS 권한 목록에는 Electron으로 표시될 수 있습니다. [Mac 사용 안내](docs/macos.md)

## 모델 설정

```dotenv
AI_PROVIDER=openrouter
OPENROUTER_API_KEY=여기에_키
OPENROUTER_MODEL=anthropic/claude-sonnet-5.5
STUDY_MODEL_PROVIDER=openrouter
STUDY_MODEL_ID=
STUDY_STT_MODEL=openai/whisper-large-v3-turbo
STUDY_GAZE_MODEL=unigaze_l16_joint
LAST_HOUR_TOKEN=24자_이상의_별도_랜덤_토큰
LAST_HOUR_DATA=./data
STUDY_HEART_URL=
STUDY_HEART_TOKEN=
```

전사는 OpenRouter `/audio/transcriptions`, 설명은 기존 이미지 지원 모델입니다. 사용료는 기존 OpenRouter 계정에 청구됩니다. 무음·전사 실패 때 설명 모델을 호출하지 않으며 세션당 AI 요청은 합계 20회입니다. AI를 끈 세션에서는 실제 질문을 전송하지 않습니다. Watch 수집 서버는 선택 사항이며 Watch 앱은 Mac 설치판에 포함하지 않습니다. 기본 모델은 OpenRouter이며, 요청한 로컬 비전 학습은 현재 중단했고, 앱은 프롬프트와 화면 맥락 연동을 사용합니다. [개인 비전 모델](docs/personal-vision.md)을 참고하세요.

UniGaze-L 체크포인트는 선택 시선 패키지에만 포함되며 약 1.22GB입니다. 설치 후에는 이 Mac의 Metal GPU에서 실행합니다. 공식 고정 revision과 SHA-256을 검증합니다. 모델 라이선스는 연구·비상업용입니다. [출처와 성능 범위](docs/neural-gaze.md)

## 저장과 검증

얼굴 영상·랜드마크·원시 시선·녹음·자동 캡처·이미지 프롬프트는 기본 기록에 저장하지 않습니다. 스크래치패드의 메모와 AI 결과 텍스트는 기기에 저장하며 패드에서 삭제할 수 있습니다. 질문할 때만 음성·선택 모니터 화면·첨부 자료의 추출 텍스트를 OpenRouter로 보냅니다. 첨부 텍스트는 앱 로컬 저장소와 세션 자료에 남으며 자료 관리에서 제거할 수 있습니다. 질문/답변 텍스트와 집계 이벤트는 `data/study`에 남습니다. 이전 버전이 남긴 정밀 보정은 현재 앱에서 불러오거나 사용하지 않습니다. 화면 기반 답변은 파인튜닝 예시로 내보내지 않습니다.

- v0.12: Node 75개, 메인 UI 30개, 채팅 UI 17개, 경고 UI 8개 통과. 실제 마이크 입력·사람별 오탐은 별도 확인이 필요합니다.
- 선택 설치 UI 8개, 실제 패키지 설치와 MPS 모델 준비, 시선 없이 실제 OpenRouter 음성 질문 약 5.31초 확인. 메인 UI 30개 흐름 통과. 스크래치패드 UI 12개 시나리오 통과: 메모·초안 복원·자료 연결·중복 업로드 차단·디자인 일치·고정·번역/요약·복사·삭제·안전한 렌더링·창 크기.
- 실제 OpenRouter 합성 한국어 음성→직접 만든 영문 화면 번역＋요약 약 6.47초. 120 ns·80 ns·40 ns·33.3% 보존 확인. 사용자 논문 PDF는 이 호출에 보내지 않았습니다.
- 사람의 마이크·OS 캡처 종합 시험, 정상 학습 오탐률은 남아 있습니다. [스크래치패드 검증](docs/scratchpad.md) · [TTS 검증](docs/tts.md).

개발용 배포 ZIP은 프로젝트에서 `python3 scripts/package_study.py`로 다시 만들 수 있습니다. 메뉴 아이콘 PNG 재생성은 Playwright 환경에서 `python3 scripts/render_tray.py`를 실행합니다.

음성 읽기는 기본 꺼짐입니다. 직접 켜면 `google/gemini-3.8-flash-tts` / Aoede를 사용합니다. 설정에서 목소리 선택·미리 듣기·Mac 기본 음성 전환을 할 수 있습니다. 앱의 **읽기 멈춤** 또는 새 질문 시작으로 재생을 멈춥니다. AI 음성은 읽을 문장을 기존 OpenRouter 계정으로 전송하며 별도 사용료가 발생합니다. 생성 음성은 디스크에 저장하지 않습니다.

설정의 모든 셀렉트는 study-select.mjs 공통 컴포넌트를 사용한다. 어두운 팝업, 화살표 중앙 정렬, 키보드 탐색/선택·취소, 비활성 옵션, 모니터 목록 갱신을 지원하며 기존 설정 값과 이벤트를 그대로 사용한다. [UI 검증](docs/qa/study-select.json). 기존 로컬 심박 수집기의 /hr 응답과 선택 자동 연결도 지원한다. [심박 서버](docs/heart-server.md).
