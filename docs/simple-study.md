# 학습 화면 정리

주요 흐름은 자료 파일 추가 → 학습 시작 → ⌘⇧Enter를 누른 채 질문 → 놓아서 전송이다. 사용자가 원하면 텍스트도 직접 붙여넣을 수 있다. 내장 PIM 예시 버튼과 자동 불러오기 경로를 제거했다. 기존에 사용자가 첨부한 자료와 원본 파일은 삭제하지 않는다.

점 따라가기, 9점 보정, 5점 검증, 화면 시선 점, 정밀 영역 선택과 관련 설정은 앱에서 제공하지 않는다. 과거 저장된 `region` 감지 모드도 더 이상 적용하지 않는다. 기본 감지는 로컬 화면 방향 신호를 이용한다. 처음 잠시 화면을 편하게 보면 기준을 자동으로 잡으며 통과/실패 단계는 없다. 인지적 집중도나 정확한 글자 위치를 판정하는 기능은 아니다. 음성 질문은 현재 화면을 첨부하며, 설정에서 필요한 문단만 고를 수 있다.

학습 화면과 설정 화면을 분리했다. 설정은 음성 질문, 화면 이탈 알림, 학습 자료, 체크리스트, AI 연결, 화면·Apple Watch·기록의 여섯 항목으로 접는다. 권한 복구·목소리·키 변경 등은 해당 항목 안에서만 펼친다. 직접 상태 보고 버튼과 기본 화면의 센서·서버 진단을 제거했다.

시작 준비 중에는 버튼에 준비 상태를 표시한다. 시작 요청 중 중복 호출을 막고, 실패하면 다시 누를 수 있게 복구한다. 이미 진행 중인 세션이 있다면 학습 화면을 다시 표시한다. 선택 시선 구성 요소 준비가 음성 학습 시작을 막지 않는다.

검증: 실제 Electron과 로컬 서버에서 시작·휴식·재개·종료·새 학습 시작을 확인했다. 별도 브라우저 시험은 이전 모드 설정을 넣어도 보정 UI 없이 이탈 알림이 발생하는지, 질문·영역 선택·음성·첨부·체크리스트·설정 이동과 시작 실패 후 재시도를 확인한다. 실제 사람의 시선 정확도와 macOS 입력 권한 시험을 자동 UI 시험으로 대체하지 않는다.
