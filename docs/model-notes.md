> 추가 구현: 검증된 보정 계수 자동 로컬 저장·동일 환경 5점 재검증. 텍스트 화면 질문은 선택한 캡처와 질문을 OpenRouter Vision으로 보내며 STT를 건너뜁니다. 원시 시선·영상은 저장하지 않습니다. 아래 과거 메모리 전용 정책은 이 변경으로 대체합니다.

> **현재 기본은 UniGaze-L(WACV 2026)**입니다. MediaPipe는 얼굴 정렬용이며 아래 이전 랜드마크 회귀 기록은 과거 구현입니다. [모델 통합 문서](neural-gaze.md)

# 시선 모델 구성과 출처 · v0.4

기본 엔진은 MediaPipe 랜드마크에서 만든 5차원 눈·머리 특징의 개인 ridge 회귀입니다. 9점 학습 후 별도 5점 검증을 통과해야 좌표와 자동 알림을 사용합니다. 단순 각도 투영이나 WebGazer로 자동 전환하지 않습니다. 보정·검증 샘플과 회귀 계수는 메모리에만 있습니다.

- MediaPipe Face Landmarker: 공식 모델과 SHA-256은 `overlay/assets/face-landmarker-source.json`에 기록했습니다. 로컬 CPU에서 실행합니다.
- `screen-gaze.mjs`: 개인 회귀와 해상도 비례 검증 게이트. 120/220 DIP px·80% 기준은 제품 초기 기준이며 실제 달성치가 아닙니다.
- `gaze.mjs`: 점별 0.9초 안정화·12개 유효 샘플, 얼굴 신호 누락·머리 위치/방향/크기 변화 품질 게이트. 큰 자세 변화가 지속되면 보정을 해제합니다.
- `pretrained-gaze.mjs` 및 MobileGaze/ONNX 자산은 이전 실험 호환 자료입니다. 현재 GazeTracker는 해당 모듈을 import하거나 실행하지 않습니다. 출처·라이선스 고지는 보존했습니다.
- WebGazer 비교, 눈 감김/졸림 분석, 화면을 보면서 딴생각하는 상태 분류는 후속 연구입니다.

사람의 시선 정확도와 오탐률은 장비 평가를 거쳐야 합니다. 자동 테스트의 합성 눈 특징 정확도를 사용자 성능으로 해석하지 않습니다. [MediaPipe 공식 문서](https://developers.google.com/mediapipe/solutions/vision/face_landmarker), [연구 검토](research-notes.md)
