# 단축키 음성 입력과 조용한 대기

- 대기·복귀·자료 준비 메시지는 우하단 창을 만들거나 표시하지 않는다. 비동기 창 로드 중 취소해도 대기 버블이 깜빡이지 않는다.
- 말하기 시작/보내기 버튼과 버블의 동의·자료 관리 폼을 제거했다. 음성 동의와 권한 안내는 설정으로 이동했다.
- 기본 입력은 ⌘⇧Enter를 누르는 동안 녹음, 놓으면 전송이다. 설정 완료 여부와 학습 세션 준비를 확인하며, 준비 전에 놓거나 취소하면 뒤늦게 녹음하지 않는다.
- 메뉴 막대의 도우미 열기와 ⌘⇧Space는 큰 앱 창을 연다. 답변·이탈 알림·진행 중 음성 요청·오류만 우하단 버블에 표시한다.

검증: Node 71개 통과, Python 89개 중 84개 통과/5개 선택 의존성 건너뜀, 브라우저 UI 30개와 버블 UI 8개 통과. 실제 실행 앱에서 말하기 버튼 0개, 대기 버블 창 0개를 확인했다. 마이크·화면·카메라 권한은 허용 상태다. 손쉬운 사용 권한은 꺼져 있어 실제 macOS 전역 키 눌림/해제 종합 시험은 건너뛰었다. 모의 키 이벤트만으로 실제 권한 검증을 통과했다고 주장하지 않는다.
