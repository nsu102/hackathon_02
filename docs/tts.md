# 자연스러운 한국어 음성

기본 읽기 엔진은 기존 OpenRouter 키를 사용하는 `google/gemini-3.8-flash-tts`다. 기본 목소리는 Aoede이고 설정에서 Kore·Charon도 선택할 수 있다. 모델 목록과 목소리는 구현 시점의 [공식 모델 API](https://openrouter.ai/api/v1/models?output_modalities=speech), 요청 형식은 [공식 TTS 계약](https://openrouter.ai/docs/guides/overview/multimodal/tts)에서 확인했다.

글 답변을 먼저 표시한 뒤 음성을 생성한다. 답변·잔소리·미리 듣기는 같은 엔진을 사용하며, 답변은 차분하게, 잔소리는 부드럽고 친근하게 전달하도록 지시한다. `Mac 기본 음성 · 로컬`도 선택할 수 있다. 자연스러움은 개인 취향과 발화 내용에 따라 달라진다.

버블과 설정에 읽기 중단 버튼이 있다. 새 질문·휴식·종료·동의 해제·목소리 변경 시 재생과 대기 요청을 취소한다. 취소 뒤 도착한 음성은 재생하지 않고 Blob URL을 해제한다. 답변 읽기 중에는 집중 알림을 유예하며 잔소리 자체의 재생으로 이탈 상태를 해제하지 않는다. 생성 실패는 글 답변을 없애거나 다른 목소리로 자동 전환하지 않는다.

읽을 문장은 명시적인 전송 동의하에 OpenRouter와 음성 제공자에게 전송된다. 음성 원본은 디스크에 보관하지 않는다. 동일한 문장·목소리·종류의 반복 알림은 제한된 프로세스 메모리 캐시로 중복 호출을 줄이며 앱 종료 때 사라진다. 한 문장은 1,800자, 새 합성은 10분당 30회, 동시에 한 요청으로 제한한다. 기존 모델 사용료에 음성 생성 사용료가 별도로 발생한다.

실제 OpenRouter 호출에서 24 kHz·mono PCM을 받고 WAV로 검증·변환했다. 작성한 한국어 예문 기준 독립 서비스 4.04초, DMG 내부 서비스 4.07초에 합성 응답을 받았다. 각 음성은 약 6.6초 길이였으며 개인 문서나 화면은 이 TTS 시험에 사용하지 않았다. `qa/macos-tts-runtime.json`, `qa/macos-dmg-tts-runtime.json` 참조.

Node에서는 대기 중 취소·재생 중 중단·자원 해제·늦은 응답·동의·오류를 확인했다. Python에서는 인증·원본 비저장·PCM 형식·잘못된 입력·반복 캐시·오류 복구를 확인했다. Chrome에서는 실제 WAV 재생, 목소리 저장, 버블 중단, 새 녹음의 음성 중단을 확인했다. 이는 사람의 청취 평가나 실제 마이크/OS 캡처 권한 시험을 대체하지 않는다.
