# Study Signal 상품 소개 페이지 디자인 기록

> 현재 제품 페이지는 Midnight Black / Pure White / Lime Green으로 다시 디자인했습니다. 최신 결과는 [Midnight product-page report](product-design-midnight.md)를 보세요. 아래는 이전 한국어 페이지의 기록입니다.

## 방향과 스킬 적용

유형은 **software**입니다. 기존 로컬 Electron 학습 도우미를 소개하는 정적 상품 페이지를 만들었으며 외부 호스팅에는 게시하지 않았습니다. 주 행동은 **제품 데모 보기**입니다.

사용자가 요청한 `Leonxlnx/taste-skill`의 프로젝트 설치본 2.5.0을 적용했습니다. 기존 추첨 결과는 centred / rose-grey-green / Outfit / nav-mega / footer-statement / close-word / space / arrow / dots였습니다. 이번 사용자가 첨부한 레퍼런스에 맞춰 색상·내비게이션·구성을 변경했습니다. 다크 브라운, 따뜻한 오렌지빛, 크림색, 큰 중앙 제목, 떠 있는 내비게이션을 사용합니다. 사용자 레퍼런스가 스킬의 평면 배경·왼쪽 정렬·고정 폭 내비게이션 규칙에 우선합니다. 스킬의 파일을 수정해 검사 결과를 바꾸지 않았습니다.

사이트에는 taste-skill의 시스템 CSS·마이크로 인터랙션을 사용했습니다. 페이지의 콘텐츠는 같은 컨테이너와 12열 리듬을 따릅니다. 배경은 사용자 레퍼런스에 따른 정적인 CSS 조명이며 WebGL·셰이더·스크롤 등장 효과·자동 전환 탭은 없습니다. reduced-motion 설정을 지원합니다.

기존 작업명 Study Signal을 유지했습니다. 상표나 도메인의 이용 가능성을 주장하지 않습니다. 마크는 이 제품을 위한 신호 모티프입니다. 참고 페이지의 이름·로고·카피·코드는 복제하지 않았습니다.

## 페이지와 동작

- 첫 화면: 공부용 AI 파트너라는 제품 분류, 9점 보정, 반투명 오버레이 미리보기, 데모 진입.
- 제품 체험: 시선 이탈·화면 복귀·필기·측정 불가 상황, 문단을 고정하는 질문 예시, 단계별 힌트, 배경 불투명도 조절.
- 시선 보정: 9개 보정 지점과 서로 다른 5개 검증 지점의 절차 체험. 클릭을 실제 시선이나 검증 통과 점수로 사용하지 않습니다.
- 마무리: 로컬 시선 처리, 질문 시 의도적 음성·화면 전송, 실제 장비 검증 범위, 설정 안내.

이 페이지는 센서를 사용하지 않는 명시적인 인터랙션 데모입니다. 답변은 작성된 예시이며 카메라·마이크·LLM 호출이 없습니다. 실제 앱 검증과 상품 페이지 검증을 구분합니다. 앱의 실측 시선 오차·오탐률·전역 단축키 검증을 웹 데모의 결과로 대체하지 않습니다.

사진·인물·고객 후기·성과 수치·가격을 만들지 않았습니다. 실제 학습 소재인 조건부 확률과 자체 오버레이를 HTML로 보여줍니다. 사진 슬롯이나 교체해야 할 외부 이미지는 없습니다. Outfit 가변 폰트와 OFL은 `product/assets/fonts`에 포함했습니다. 모든 리소스를 로컬에서 제공합니다.

## 브라우저 검증

Node 24와 시스템 Chrome에서 taste-skill 스크립트를 한 번에 하나씩 실행했습니다.

- 최종 인터랙션 23개 통과: 네 상황별 응답, 선택 상태, 복귀, 투명도, 양쪽 탭 패널, 질문 문단 강조, 단계별 힌트, 키보드 탭 전환, 9→5→9 절차, 모바일 메뉴 열기/링크 선택·Escape 시 닫기, 메뉴가 전체 뷰포트를 덮는지 확인, 모바일 하단 버튼 44px 이상·내용 수용, 로컬 리소스만 사용.
- 실제 레이아웃: 1440×900, 1024×768, 820×1180, 768×1024, 390×844에서 가로 넘침 없음. 실제 제목은 2줄이며 보정 화면·제품 UI가 모두 그려집니다. 마지막 layout-check 결과는 사용자 지시로 만든 떠 있는 내비게이션 내부 여백만 지적했습니다. 본문 그리드 오류나 합성 제목 스트레스 오류는 없습니다.
- 성능 1회씩, 1440/390: 약 179.3 KiB 전송, CLS 0, 요청 실패 0, 긴 작업 0, WebGL 컨텍스트 0. 성능 검사 **0 FAIL / 2 WARN**. WARN은 0.4 KiB짜리 같은 로고 SVG의 below-fold lazy 속성에 관한 것입니다. 외부 네트워크 환경에서의 지연 보장은 아닙니다.
- HTML 고유 ID와 로컬 링크·파일을 확인했습니다. 별도 설정 안내 페이지도 연결했습니다.

## 추가 일관성·성능 검사 결과

전체 일관성 검사(5개 폭)는 FAIL 35 / WARN 27을 보고했습니다. 태블릿 주요 버튼 숨김, 태블릿 자료 위에 겹치는 응답 미리보기, 모바일 하단 12px 여백 초과, 마지막 보정 섹션의 행동 버튼을 수정했습니다. 820·768·390 대상 빠른 재검사에서 해당 nav/CTA/section-height FAIL과 overlap-text 경고가 사라졌습니다. 재검사에는 FAIL 11 / WARN 13이 남았습니다. 이 중 버튼 높이 지적 후 보정 CTA의 small 크기 클래스를 제거했습니다.

남은 형식 지적은 중앙 정렬 hero를 본문 왼쪽 정렬 규칙으로 측정한 경우, 패딩 있는 내비게이션의 안쪽을 외곽과 비교한 경우, 상호작용 컨트롤·보정 화면을 일반 text-left split으로 판정한 경우입니다. 선택한 centred hero와 제품 UI 체험 구성을 유지한 설계 예외로 기록합니다. 반투명 어두운 앱 패널의 글자 대비를 뒤의 밝은 문서색으로 계산한 경고, 한국어 제목을 1단어로 처리한 경고도 원본 결과에 보존했습니다. 스타일 검사 전체 통과를 주장하지 않습니다.

최종 레이아웃 재검사(1440·820·768·390)는 가로 넘침이 없으며 nav 내부/외부 경계 지적 각 2건만 남았습니다. 태블릿에서 자료 문단과 응답 미리보기가 겹치지 않는 이미지를 확인했습니다. 성능 검사는 FAIL 0 / WARN 2, 깨진 요청 0, CLS 0입니다. 경고는 작은 브랜드 SVG의 아래쪽 반복 배치에 lazy 속성이 없다는 내용입니다. CPU 헤드리스 합성 수치이며 실제 사용자 성능을 보장하지 않습니다.

## 상품 페이지 최종 전달 검사

2026-11-07 최종 소개 페이지는 다크 브라운·오렌지빛 centred hero, 패딩 있는 floating nav, Outfit/시스템 한글 폰트, 자체 학습 화면, 스킬의 시스템·모션 계층을 사용합니다. 사이트 유형은 software이며 주 행동은 ‘제품 데모 보기’입니다. 사진·후기·가격의 가정이나 교체용 이미지 슬롯은 없습니다. 로컬에서만 제공하며 호스팅 배포는 하지 않았습니다.

최종 인터랙션 **23 PASS / 0 FAIL**을 실제 브라우저에서 확인했습니다. 키보드 탭으로 이동할 때 문단 강조가 복원되고, 모바일 메뉴가 floating header 안에 잘리지 않고 전체 뷰포트를 덮으며, Escape로 닫힙니다. 모바일 하단 버튼은 높이 44px을 유지하고 안내 문구·법적 고지가 화면 안에 들어오는지 확인했습니다. 9점→별도 5점→처음으로 돌아오는 과정에서도 실제 시선 점수나 검증 통과를 생성하지 않습니다.

최종 전체 일관성 검사는 **13 FAIL / 11 WARN**을 반환했습니다. 남은 FAIL은 모두 `container-edges`입니다. 각 지적을 아래 세 가지 설계 예외로 판정했습니다.

1. 10건: 사용자 레퍼런스에 따른 중앙 hero 제목·설명·안내 pill·미리보기를 일반 본문 왼쪽 정렬 규칙으로 판정합니다. 실제 중앙축과 좌우 여백은 일치하며 양옆으로 넘치지 않습니다. 사용자 지시에 따라 중앙 구성을 유지했습니다.
2. 2건: 떠 있는 내비게이션의 로고·버튼 안쪽 패딩을 페이지 외곽선과 비교합니다. 컨테이너 외곽은 본문과 같고, 내용의 패딩은 사용자 레퍼런스에 따른 선택입니다.
3. 1건: 데스크톱 `#study-demo`는 실제 12열 CSS grid의 9열(x 406–1360)에 놓입니다. 이 커스텀 grid 행을 전체 폭 단일 박스로 분류한 지적이며 좌우 페이지 넘침이 아닙니다.

WARN에는 한국어 제목의 단어 수, 작은 hero UI의 면적, 섹션 간 여백 차이, 로고가 처음으로 이동하는 링크, 보정 안내 버튼의 폭 등이 있습니다. 반투명 패널의 글자 대비는 검사기가 뒤쪽의 밝은 PDF 색으로 비교해 경고합니다. 화면 확인에 더해 최종 라벨을 밝게 조정하고, 가장 투명한 72% 설정을 완전한 흰색 위에 합성한 보수적 배경에서 주요 글자·상태·후속 힌트·질문 텍스트가 모두 4.5:1 이상인지 별도로 계산했습니다. 이 색상 보완은 레이아웃이나 동작을 바꾸지 않습니다. 검사기 파일은 변경하지 않았고 전체 스타일 검사 통과를 주장하지 않습니다.

1440/1024/820/768/390 전체 화면을 확인했으며, 최종 5개 크기 layout-check에는 내비게이션 내부 패딩 지적만 남았습니다. 최종 모바일은 하단을 1개 화면으로 정리한 6개 화면 길이이고 데스크톱은 4개 화면입니다. 성능 측정은 약 179 KiB, CLS 0, 요청 실패 0, **0 FAIL / 2 WARN**입니다. 작은 로고 SVG의 lazy 속성 경고를 기록합니다. 실제 네트워크나 센서 성능에 대한 수치가 아닙니다.
