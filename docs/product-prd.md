# Study Signal v0.10 제품 기획

macOS 브라우저·PDF 학습자를 위한 메뉴 막대 앱과 우하단의 반투명 채팅 버블. 정확한 글자 위치 추적은 필수 흐름에서 제외하고, 음성 질문과 화면 응시·이탈 신호를 제공한다.

## 사용자 흐름

목표 입력 → 학습 시작 → 화면 가운데 약 2초 응시 → 학습. 궁금하면 ⌘⇧Enter를 누른 채 질문하고 놓아서 전송한다. 대기 버블과 말하기 시작 버튼은 표시하지 않는다. 시작 시점의 선택 모니터 화면·질문·첨부 자료의 추출 텍스트를 OpenRouter로 보낸다. 설정·기록·자료 관리만 별도 큰 창을 연다. 답변과 이탈 알림을 별도 버블에 표시하고 선택적으로 OS 음성으로 읽는다. 텍스트 질문창·힌트/설명/복습 프리셋은 제공하지 않는다.

질문 범위는 전체 선택 모니터 또는 녹음 후 시작 화면에서 직접 고른 문단이다. 카메라 위치 보정 실패가 질문을 막지 않는다. 음성·화면 전송은 UI에 명시하고 동의 체크를 요구한다. 전체 모니터를 보내는 기본값을 작은 크롭으로 오해하게 표시하지 않는다.

## 집중 신호

UniGaze-L 얼굴 영상 추론의 시선·머리 방향을 현재 실행의 짧은 정면 기준과 비교한다. 기본 모드에는 9점 보정·학습 영역 지정이 필요 없다. attending, away_pending, away, unknown, paused, helping을 사용하며 unknown 원인을 표시한다. 실제 인지적 집중이나 이해도·딴생각을 판정하지 않는다.

8초 이탈 시 시각 알림, 20초에 짧은 음성 알림, 2초 복귀에 해제, 반복 90초 제한. 얼굴 가림·불확실한 신호·질문/답변·휴식·생각/필기 유예는 예외다. 감도·말투·음소거·끄기·오탐 정정을 제공한다. 기준은 이탈 중 자동으로 새로 학습하지 않는다.

## 메뉴 막대와 간단한 설정

파형 시그널 SVG와 1×/2× 템플릿 이미지 사용. 메뉴에서 설정, 도우미 열기, 카메라 감지, 이탈 알림, 음소거, 휴식, 종료를 제어한다. 창을 닫으면 숨겨지고 감지는 계속한다. 백그라운드 렌더러 타이머를 억제하지 않는다.

보정·검증·화면 시선 점·정밀 영역 설정과 내장 논문 예시를 제거한다. 학습과 설정을 별도 화면으로 나누고 설정은 여섯 개 접는 항목으로 제공한다. 화면 방향 감지와 음성 질문에 보정 통과 조건을 두지 않는다.

## 데이터·범위·검증

OpenRouter 기존 계정·모델 설정을 유지한다. 얼굴 영상과 원시 시선은 로컬 메모리만 사용하고 음성·화면·이미지 프롬프트는 기본 기록에 저장하지 않는다. 질문/답변 텍스트와 상태 전이 집계만 저장한다. Watch 서버 연동은 선택 사항이다. 개인 비전 학습은 중단했고 OpenRouter 추론을 사용한다. 파인튜닝했다고 표시하지 않는다. UniGaze 모델은 연구·비상업용 라이선스다.

소프트웨어 경로·상태 전이·합성 음성 실호출과 실제 사용자 정확도·오탐률은 구분한다. 사람/조명/안경/기기별 실측, 마이크·화면 권한 종합 시험, 전역 키 실측이 남아 있다. [검증 결과](study-validation.md)

## 첨부와 설치

PDF/TXT/MD/DOCX 최대 5개, 파일당 20 MB. PDF 첫 40페이지·파일 24,000자·합계 30,000자를 사용한다. 원본은 복사하지 않고 추출 텍스트를 로컬에 저장한다. 질문 중에는 자료를 바꾸지 않는다. Apple Silicon/macOS 15+ DMG에 런타임과 기본 모델을 포함하며 개인 키·데이터는 제외한다. 개발용 ad-hoc 서명이며 Apple 공증은 별도다. [v0.8 검증](qa-v08.md)

## 현재 핵심 흐름: 읽으며 정리하는 패드

좌상단의 작고 반투명한 패드가 메모·붙여넣은 텍스트와 AI 결과를 담는다. 논문을 읽다 “이거 번역해줘”라고 음성 요청하면 알겠습니다 안내 후 화면 번역과 핵심 요약이 한 블록으로 추가된다. 요약 요청도 같은 경로를 사용한다. 화면 밖의 논문 전체를 이해했다고 주장하지 않는다. 결과를 복사/삭제하고 메모는 수정한다. 작성 중 초안과 결과는 재실행 후 복원한다.

파일은 학습 시작의 자료 추가에서 한 번 선택하며 같은 세션의 음성 질문이 재사용한다. 패드에는 별도 파일함/파일 업로드를 두지 않는다. 두 창의 색·폰트·헤더·버튼·불투명도는 공유한다. 좌상단 학습 목록은 패드가 열린 동안 겹치지 않게 숨긴다. 기존 우하단 버블은 말하기·처리 상태·완료 알림을 맡는다.
