# Study Signal v0.6 제품 기획

macOS 브라우저·PDF 학습자를 위한 메뉴 막대 앱과 반투명 음성 도우미. 정확한 글자 위치 추적은 필수 흐름에서 제외하고, 음성 질문과 화면 응시·이탈 신호를 제공한다.

## 사용자 흐름

목표 입력 → 학습 시작 → 화면 가운데 약 2초 응시 → 학습. 궁금하면 ‘말하기 시작’ → 질문 → ‘말 끝내고 보내기’. 시작 시점의 선택 모니터 화면과 질문을 OpenRouter로 보낸다. 답변을 표시하고 선택적으로 OS 음성으로 읽는다. 텍스트 질문창·힌트/설명/복습 프리셋은 제공하지 않는다.

질문 범위는 전체 선택 모니터 또는 녹음 후 시작 화면에서 직접 고른 문단이다. 카메라 위치 보정 실패가 질문을 막지 않는다. 음성·화면 전송은 UI에 명시하고 동의 체크를 요구한다. 전체 모니터를 보내는 기본값을 작은 크롭으로 오해하게 표시하지 않는다.

## 집중 신호

UniGaze-L 얼굴 영상 추론의 시선·머리 방향을 현재 실행의 짧은 정면 기준과 비교한다. 기본 모드에는 9점 보정·학습 영역 지정이 필요 없다. attending, away_pending, away, unknown, paused, helping을 사용하며 unknown 원인을 표시한다. 실제 인지적 집중이나 이해도·딴생각을 판정하지 않는다.

8초 이탈 시 시각 알림, 20초에 짧은 음성 알림, 2초 복귀에 해제, 반복 90초 제한. 얼굴 가림·불확실한 신호·질문/답변·휴식·생각/필기 유예는 예외다. 감도·말투·음소거·끄기·오탐 정정을 제공한다. 기준은 이탈 중 자동으로 새로 학습하지 않는다.

## 메뉴 막대와 정밀 시선

눈·음성 파형 SVG와 1×/2× 템플릿 이미지 사용. 메뉴에서 설정, 도우미 열기, 카메라 감지, 이탈 알림, 음소거, 휴식, 종료를 제어한다. 창을 닫으면 숨겨지고 감지는 계속한다. 백그라운드 렌더러 타이머를 억제하지 않는다.

정밀 좌표는 실험 설정에 남긴다. 9점 학습＋별도 5점 검증, 12개 유효 샘플, 120/220 DIP px·유효율 80%의 해상도 비례 기준을 유지한다. 통과한 계수는 로컬 저장, 같은 환경에서는 5점 재검증. 실패는 정밀 좌표만 차단한다.

## 데이터·범위·검증

OpenRouter 기존 계정·모델 설정을 유지한다. 얼굴 영상과 원시 시선은 로컬 메모리만 사용하고 음성·화면·이미지 프롬프트는 기본 기록에 저장하지 않는다. 질문/답변 텍스트와 상태 전이 집계만 저장한다. Watch 서버 연동은 선택 사항이다. GPU 서버·SSH·파인튜닝은 범위에서 제외한다. UniGaze 모델은 연구·비상업용 라이선스다.

소프트웨어 경로·상태 전이·합성 음성 실호출과 실제 사용자 정확도·오탐률은 구분한다. 사람/조명/안경/기기별 실측, 마이크·화면 권한 종합 시험, 전역 키 실측이 남아 있다. [검증 결과](study-validation.md)
