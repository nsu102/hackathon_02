# Study Signal v0.10 구현 상태

현재 중심 흐름은 **좌상단 스크래치패드 + 음성 화면 번역·요약**이다. 로컬/GPU 학습과 파인튜닝 API 조사는 사용자 요청으로 중단했다. 기본 추론은 기존 OpenRouter 계정을 사용한다. 실제 학습된 개인 모델은 없다.

| 항목 | 결과 | 검증 |
|---|---|---|
| 스크래치패드 | 좌상단 반투명 창, 메모·초안·파일·이미지, 편집/복사/삭제/고정, 로컬 복원 | Node 저장·첨부·네이티브 경계, Chrome UI 10개 |
| 음성 요청 | 먼저 알겠습니다 안내, 시작 화면 고정, 전사 후 번역/요약/일반 질문 분기 | 실제 OpenRouter 합성 음성 경로 6.47초 |
| 화면 번역 | 현재 화면 번역과 핵심 요약을 같은 블록에 기록, 출처 범위 표시 | 수치·단위 보존, 출력 계약·오류 시험 |
| 기존 Mac 기능 | 메뉴 아이콘·우하단 버블·자연스러운 TTS·자료 관리·학습 목록 유지 | 기존 회귀 시험 포함 |
| 개인정보 | 자동 캡처/녹음 미저장, 사용자 패드 첨부만 로컬 복사 | 첨부 형식·크기·경로 검증, 매체 미저장 확인 |
| 배포 | Apple Silicon macOS 15 이상 DMG, 독립 Python/MPS 포함 | 읽기 전용 이미지 검사 |

소프트웨어 완료와 실제 장비 검증을 구분한다. 사람의 마이크·OS 권한·전역 키 종합 시험, 장시간 이탈 오탐률, Developer ID 서명/Apple 공증은 남아 있다. 시선은 화면 방향 신호이며 인지적 집중도·딴생각을 검증한 분류기가 아니다. [상세 시나리오](scratchpad.md)
