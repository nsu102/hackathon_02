# Study Signal v0.12.2 구현 상태

현재 중심 흐름은 **작은 채팅창 + 클릭 음성·텍스트 화면 질문**이다. 로컬/GPU 학습과 파인튜닝 API 조사는 사용자 요청으로 중단했다. 기본 추론은 기존 OpenRouter 계정을 사용한다. 실제 학습된 개인 모델은 없다.

| 항목 | 결과 | 검증 |
|---|---|---|
| 스크래치패드 | 반투명 창, 초안·AI 결과·로컬 복원, 공통 디자인, 상태 표시를 학습 창으로 통합 | Node 저장·첨부·네이티브 경계, 채팅 UI 17개 |
| 음성 요청 | 클릭 말하기/보내기, 음성 단축키 제거, 시작 화면 고정, 전사 후 설명 | 실제 OpenRouter 합성 음성 경로 6.47초 |
| 화면 번역 | 현재 화면 번역과 핵심 요약을 같은 블록에 기록, 출처 범위 표시 | 수치·단위 보존, 출력 계약·오류 시험 |
| 기존 Mac 기능 | 메뉴 아이콘·별도 빨간 경고 다이얼로그·자료 관리·학습 목록 유지, TTS 기본 꺼짐 | 기존 회귀 시험 포함 |
| 개인정보 | 자동 캡처/녹음 미저장, 파일 추가는 기존 학습 자료 한 곳으로 통일 | 기존 자료 프롬프트 전달·중복 업로드 차단 확인 |
| 배포 | Apple Silicon macOS 15 이상 DMG, 작은 독립 Python 기본판 + 별도 선택 MPS 패키지 | 읽기 전용 이미지 검사 |

소프트웨어 완료와 실제 장비 검증을 구분한다. 사람의 마이크·OS 권한 종합 시험, 장시간 이탈 오탐률, Developer ID 서명/Apple 공증은 남아 있다. 시선은 화면 방향 신호이며 인지적 집중도·딴생각을 검증한 분류기가 아니다. [상세 시나리오](scratchpad.md)

추가 완료: 기본 DMG에서 시선 모델/PyTorch/OpenCV 제거, 앱 설정의 시선 패키지 설치·검증·취소·진행률, 설치 전 카메라 자동 시작 차단. 실제 분리 패키지 설치와 MPS 준비, 기본판의 OpenRouter 음성 질의·화면/PDF 설명을 확인했다. [선택 설치](optional-gaze.md)

추가 검증: v0.12.2 Node 80개·메인 UI 31개 통과. 수정 DMG를 /Applications에 설치하고 Launch Services로 실행한 실제 설치판에서 화면 권한 denied를 확인했다. 이 앱의 ScreenCapture 기록만 초기화하고 OS 재허용을 요청했다. 재허용 후 캡처 성공은 아직 확인하지 않았으며 qa/release-v0122.json에 상태를 기록한다. v0.12.1의 채팅·경고창 비중첩 네이티브 시험 기록은 별도로 유지한다.
