# Mac에서 사용하기 · v0.11

`학습 보조 실행.command`를 실행하면 메뉴 막대와 좌상단 학습 창이 열린다. 우하단 버블은 질문·답변·이탈 알림이 있을 때만 나타난다. Python 3.13+/Node.js 22+, 기존 OpenRouter 키가 필요하다. 처음 신경망 모델을 준비할 때 다운로드가 발생한다. 소스 실행과 v0.11 Apple Silicon DMG 개발 설치판을 제공한다. Apple Developer ID 서명·공증은 포함하지 않는다.

## 메뉴 막대

상단의 파형 시그널 아이콘을 누르고 **설정…**을 고른다. 같은 메뉴에서 감지 켜기/끄기, 이탈 알림, 잔소리 음소거, 휴식, 도우미 열기, 종료를 선택할 수 있다. 닫기(×)는 창만 숨기고 감지는 유지한다. Cmd+Shift+Space로 다시 표시할 수 있다.

SVG 원본: `overlay/assets/StudySignalTemplate.svg`. macOS 표시에는 투명 16×16/72dpi와 32×32/144dpi 템플릿 PNG를 함께 사용한다. 이름의 Template/@2x 규칙과 setTemplateImage를 적용해 밝고 어두운 메뉴 막대에 대응한다. [Electron Tray](https://www.electronjs.org/docs/latest/api/tray), [NativeImage](https://www.electronjs.org/docs/latest/api/native-image).

## 감지

시선 추가 패키지가 설치된 경우에만 학습 시작 시 카메라를 준비한다. 미설치 상태에서는 음성 도움을 그대로 사용한다. 화면 가운데를 약 2초 바라보면 기본 화면 방향 기준을 잡는다. 설정의 감도는 여유롭게/보통/민감하게다. 자리나 거리가 바뀌면 **화면 기준 다시 잡기**를 누른다. ‘측정 불가’일 때는 이유가 표시되며 알림을 보내지 않는다. 실제 인지적 집중을 판정하는 기능으로 보지 않는다.

정밀 위치 보정은 실험 설정이며 기본 감지와 음성 질문에 필수적이지 않다. 통과한 정밀 보정은 이 Mac에 저장되고 같은 환경이면 5점 재검증으로 사용할 수 있다.

## 음성

‘음성·현재 화면·첨부 자료를 OpenRouter로 전송’ 체크 → 설정에서 음성 단축키 켜기 → ⌘⇧Enter를 누른 채 질문 → 키를 놓아 전송. 화면 범위는 선택 모니터 전체 또는 매번 문단 선택이다. 전체 모니터 옵션은 그 모니터 전체를 전송한다. 기본 자연스러운 AI 음성 읽기는 설정에서 끄거나 Mac 기본 음성으로 바꿀 수 있다.

음성 질문은 카메라 없이도 쓸 수 있다. 마이크·화면 녹화 권한은 필요하다. 개발 버전은 시스템 권한 목록에 Electron으로 나타날 수 있다. 권한 변경 후 재시작이 필요하면 앱에 안내가 나온다. 운영체제의 권한 스위치를 앱이 대신 바꾸지 않는다.

음성 입력은 전역 Cmd+Shift+Enter를 사용한다. 누르는 동안 녹음하고 놓으면 전송하며 손쉬운 사용/입력 모니터링 권한이 추가로 필요할 수 있다. 최대 20초 watchdog은 자동 보내기가 아니라 녹음 폐기다. 얼굴 영상·녹음·화면을 기본 기록에 보관하지 않는다.

## v0.11 DMG 설치판

`Study-Signal-0.11.0-arm64.dmg`는 Apple Silicon(M1 이상), macOS 15 이상용이다. DMG를 열어 Study Signal.app을 Applications로 옮겨 실행한다. Electron·가벼운 Python 백엔드를 포함해 Node.js/Homebrew/Python을 별도로 설치하지 않는다.

설정은 **⌘,**(앱에 포커스가 있을 때) 또는 메뉴 막대 아이콘 → 설정에서 연다. OpenRouter 키를 입력하고 ‘저장 후 앱 다시 시작’을 누른다. 키 입력칸을 비우면 기존 키를 유지한다. 진행 중인 학습은 종료한 뒤 저장한다.

설치판의 설정·보정·학습 기록은 `~/Library/Application Support/Study Signal`에 보관한다. API 키는 이 위치의 `.env`에 현재 사용자만 읽도록 저장하며 DMG에 포함하지 않는다. 정밀 보정과 센서 원본의 기존 저장 정책은 그대로다.

이 빌드는 ad-hoc 무결성 서명이며 Apple Developer ID 서명·Apple 공증은 포함하지 않는다. 다른 Mac이나 인터넷 배포 환경의 Gatekeeper 동작을 공증된 상용 설치판과 같다고 보장하지 않는다. 모델의 연구·비상업용 라이선스 고지는 앱 안에 포함한다.

개발자가 다시 빌드하려면 신경망 환경에 `scripts/macos-build-requirements.txt`를 설치하고, Playwright와 Chrome이 있는 Python으로 `python3 scripts/build_macos.py`를 실행한다. `--reuse-service`는 독립 서비스 재빌드를 생략한다. 빌드 작업은 `.build`에만 모으고 완성 DMG는 상위 outputs에 생성한다.

## 버블·자료·단축키

답변과 이탈 알림은 우하단의 별도 버블에서 표시한다. 버블은 다른 앱의 입력 포커스를 가져오지 않는다. 설정·기록·자료 관리만 큰 창을 연다. 화면 캡처 시 자체 창을 숨긴다.

자료 추가는 PDF·TXT·MD·DOCX를 지원한다. 최대 5개, 각 20 MB이며 원본 대신 추출 텍스트를 로컬에 저장한다. PDF 앞 40페이지/파일 24,000자/전체 30,000자 제한이 있다. 스캔 PDF는 화면에 열어 질문한다.

| 단축키 | 동작 |
|---|---|
| Cmd+Shift+Space | 도우미 표시/숨김 |
| Cmd+, | 앱에 포커스가 있을 때 설정 |
| Cmd+Shift+Enter | 설정에서 켠 경우 누르는 동안 녹음, 놓으면 전송 |

[최종 시험 결과와 실기기 미검증 항목](qa-v08.md).

## 자연스러운 음성 · v0.11

OpenRouter의 Gemini TTS를 기본으로 사용한다. 연결 키는 기존 키 그대로다. 설정 → 음성 질문에서 아오이데/코레/카론 중 선택하고 미리 듣는다. 답변과 잔소리에 같은 목소리를 사용한다. 글 답변을 먼저 표시하고 음성을 준비한다. 버블의 읽기 멈춤·새 질문·휴식·동의 해제로 준비/재생 중인 음성을 취소한다. 늦게 도착한 응답은 재생하지 않는다. 오류 때 기본 음성으로 몰래 전환하지 않으며 글 답변을 유지한다.

읽을 문장을 OpenRouter와 음성 제공자에게 전송한다. 오디오는 메모리에서만 처리하며 반복 알림은 앱 실행 중에만 제한된 캐시를 사용한다. [구현과 검증](tts.md)

## 좌상단 패드

실행하면 선택 모니터 좌상단에 반투명 스크래치패드가 열린다. 메뉴 막대 → 스크래치패드 열기 또는 앱 포커스 상태에서 ⌘⇧P로 연다. 고정 핀을 끄면 항상 위 표시를 해제한다. 숨겨도 메모/초안/첨부는 남는다. 파일은 학습 시작에서 한 번만 추가하고 패드에서는 같은 자료를 그대로 사용한다. 별도 파일 추가 버튼은 없다.

논문을 열고 ⌘⇧Enter 누르기 → “이거 번역해줘” → 키 놓기. 알겠습니다 안내 뒤 번역과 요약이 패드에 저장된다. 음성 읽기를 끈 경우 안내도 글로만 표시한다. 패드 데이터를 저장하는 위치는 설치판의 data/scratchpad이며 기본 Application Support 안에 있다.

## 시선 감지 추가 설치

기본 DMG에는 PyTorch·OpenCV·UniGaze 모델이 없다. 시선 기능은 별도 Study-Signal-Gaze-arm64-v1.zip을 다운로드하고 설정 → 시선 감지 설치…에서 선택해 설치한다. 진행률과 취소를 지원한다. 키/기록을 변경하지 않으며 설치된 구성 요소는 Application Support/Study Signal/components/gaze-v1에 남는다. 설치 후 감지 켜기를 눌러 카메라를 시작한다. [자세한 검증](optional-gaze.md)
