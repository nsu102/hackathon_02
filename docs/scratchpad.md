# 좌상단의 작은 채팅창 · v0.11.2

평소에는 340×116 DIP의 반투명 창에 질문 입력칸과 채팅하기 버튼만 둔다. 텍스트 질문은 버튼 또는 Enter로 보낸다. Shift+Enter는 줄바꿈이다. 음성은 기존 ⌘⇧Enter를 누른 동안 녹음하고 놓아서 보낸다.

질문을 보내거나 음성 녹음을 시작하면 400×520 DIP로 대화 영역이 펼쳐진다. 입력 질문·진행 상태·답변·번역·요약이 표시된다. 접기는 입력창 크기로 돌아가며 기록을 지우지 않는다. 대화 버튼으로 다시 열 수 있다. 앱을 다시 실행할 때에는 과거 대화가 있어도 작은 입력창으로 시작한다. 복사와 삭제는 완료된 결과에 제공한다. 기존 메모와 초안은 임의 삭제하지 않는다.

텍스트와 음성 모두 질문 시작 시점의 선택 모니터를 참고한다. 설정의 전송 동의가 없으면 업로드를 시작하지 않고 동의 설정으로 이동한다. 영역 선택을 설정한 경우 문단을 직접 고른다. 자료 파일은 학습 설정의 기존 파일 추가에서 관리한다. 얼굴 영상·자동 캡처·녹음은 기본 기록에 저장하지 않는다. 질문·답변·초안은 기존 기기 저장소에 보관한다.

검증: Node 74개, 채팅 UI 17개, 메인 UI 30개 통과. 실제 네이티브 창의 340×116→400×520→340×116 전환, 접은 뒤 기록 유지, 음성 대기 표시, 텍스트 질문의 메인 컨트롤러 전달과 동의 차단을 확인했다. 합성/모의 입력 시험을 실제 마이크·시선 정확도 시험으로 표시하지 않는다.

테스트용 전체 화면 페이지와 이를 여는 코드·파일을 제거했다. 일반 빌드에도 qa-로 시작하는 테스트 화면을 포함하지 않는다. 이후 UI 확인은 화면을 가리지 않는 브라우저 모의 시험을 사용한다.
