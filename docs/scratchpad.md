# 작은 채팅창 · v0.12.2

평소에는 340×116 DIP의 반투명 창에 질문 입력칸과 채팅하기·말하기 버튼을 둔다. 시간·심박수·시선 상태는 별도 학습 창에 모으며 채팅 위에는 표시하지 않는다. 텍스트 질문은 버튼 또는 Enter로 보낸다. Shift+Enter는 줄바꿈이다. 음성은 말하기를 클릭해 시작하고 보내기를 클릭해 전송한다. 음성 전역 단축키는 제거했다.

질문이나 녹음을 시작하면 400×520 DIP로 대화가 펼쳐진다. 입력 질문·진행 상태·답변·번역·요약은 이 창 한 곳에 표시한다. 접어도 기록은 유지되며 대화 버튼으로 다시 연다. 재실행하면 작은 입력창으로 시작한다. 파일은 학습 설정에서 추가한 자료를 재사용한다.

텍스트는 전송 시점, 음성은 녹음 시작 시점의 선택 모니터 전체 화면을 자동 첨부한다. 전송 동의가 없으면 업로드를 시작하지 않는다. 답변 읽기는 기본 꺼짐이다. 얼굴 영상·자동 캡처·녹음은 기본 기록에 저장하지 않는다. 질문·답변·초안은 기기에 보관한다. 채팅창에는 심박·시간·시선 상태를 전달하거나 표시하지 않는다.

집중 이탈은 별도 빨간 다이얼로그로 알린다. 채팅·목록 창을 피해서 배치하며 공간이 없으면 겹쳐 표시하지 않는다. 답변용 추가 버블은 만들지 않는다. macOS 기본 알림은 사용하지 않는다.

검증: Node 75개, 채팅 UI 17개, 메인 UI 30개, 경고 UI 8개 통과. 모의 음성과 화면을 사용한 자동 시험을 실제 마이크·시선 정확도 시험으로 표시하지 않는다. 설치판 네이티브 시험 결과는 qa/native-scratchpad.json에 기록한다.
