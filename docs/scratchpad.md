# Study Signal v0.10.1 · 화면 번역 스크래치패드

선택 모니터의 좌상단에 반투명 패드를 띄운다. 논문/PDF를 읽으며 음성으로 요청한 번역·요약을 누적하고, 메모와 텍스트 결과를 모은다. 학습 시작에 추가한 자료를 그대로 참고하며 별도 파일함을 만들지 않는다. 현재 모델은 OpenRouter 추론이며 별도 파인튜닝 가중치를 사용하지 않는다.

## 사용

1. 메뉴 막대 아이콘 → 설정에서 OpenRouter 키와 마이크·화면 녹화 권한을 확인한다. 음성·현재 화면·질문용 첨부 자료 전송에 동의하고 음성 단축키를 켠다.
2. 논문을 화면에 연다. **⌘⇧Enter를 누른 채 “이거 한국어로 번역해줘”라고 말하고 놓는다.** 단축키는 설정에서 바꿀 수 있다.
3. **알겠습니다** 안내가 나타난다. 음성 읽기가 켜져 있으면 말로도 안내한다. STT 후 질문 시작 시점의 고정 화면을 설명 모델에 전달한다.
4. 패드에 번역 본문·핵심 요약·읽은 범위가 들어온다. “이 부분 요약해줘”는 요약 블록을 만든다. 일반 화면 질문의 답변도 같은 패드에 저장한다.
5. 새 메모를 적거나 붙여넣고 메모 추가를 누른다. 텍스트를 붙여넣거나 끌어 놓을 수 있다. 별도 파일 선택/파일 드롭 업로드는 제공하지 않는다. 메모는 편집하고, 결과는 복사/삭제한다. 초안과 블록은 재실행 후 복원한다.

닫기 대신 숨김을 사용하며 메뉴 → 스크래치패드 열기 또는 **앱에 포커스가 있을 때 ⌘⇧P**로 다시 연다. 핀은 항상 위 표시를 전환한다. 학습 목록과 겹치지 않게 전환하고, 질문 화면 캡처에서는 앱의 자체 창을 숨긴다.

## 범위와 저장

보이는 화면만 번역한다. 화면 밖 페이지나 논문 전체를 읽었다고 가정하지 않는다. 작은 글자·잘린 문단·흐린 수식은 오독할 수 있어 문단 선택이나 화면 확대를 사용할 수 있다. 모델 응답에는 출처 범위/한계를 표시하며 실제 숫자와 수식은 원문과 대조할 수 있다.

파일은 학습 시작의 자료 추가(PDF/TXT/MD/DOCX)에서 한 번 넣는다. 해당 세션의 자료 텍스트와 현재 화면이 음성 질문 맥락에 함께 포함된다. 패드는 연결된 자료 이름을 표시하며 다시 파일을 선택하지 않는다. 패드 IPC에서도 파일 추가/파일 열기 동작을 받지 않는다.

메모·번역/요약 텍스트·초안은 설치판 Application Support 아래 data/scratchpad에 보관한다. 예전 버전에 이미 넣었던 파일 복사본은 임의 삭제하지 않으며 새 패드에서는 표시/추가하지 않는다. 질문 녹음·자동 화면 캡처·얼굴 영상·원시 시선은 기본 기록에 저장하지 않는다. 중단/실패한 요청을 완료된 번역으로 복원하지 않는다.

학습 창과 패드는 study-theme.css의 글꼴·무채색 토큰·헤더·로고·버튼을 공유한다. 불투명도 설정도 두 창에 함께 적용한다.

## 확인 결과

- Node 71개 통과, Python 89개 중 87개 통과/기존 OpenAI SDK 전용 2개 제외.
- 메인 UI 30개 흐름: 실제 합성 마이크 WebM/Opus, 단축키 눌림/해제 이벤트, 취소, 번역/요약 패드 저장, TTS 중단 등. 네이티브 캡처/키 훅은 이 시험에서 모의 처리했다.
- 패드 UI 12개 시나리오: 메모, 초안 복원, 기존 자료 연결/갱신, 중복 파일 업로드 차단, 학습 창과 계산된 스타일 일치, 핀, 대기 안내, 번역+요약, 복사, 안전한 문자열 렌더링, 삭제, 360/420/720px 레이아웃.
- 빌드한 Mac 설치판 앱의 실제 Electron 창에서 패드 생성, 메모 저장, 대기→번역 완료 블록 교체, 요약 표시와 새로고침 복원 확인. 좌상단 bounds는 x=20/y=58, 420×560 DIP였다.
- 실제 OpenRouter 호출: 합성 한국어 “이거 한국어로 번역해줘. 핵심 요약도 같이 정리해줘.” + 직접 작성한 영문 화면 → 한국어 번역과 요약 **6.47초**. 120 ns→80 ns, 감소40 ns/33.3%와 예시라는 한계를 보존했다. 사용자의 논문 PDF는 이 호출에 전송하지 않았다.

사람의 실제 마이크·OS 캡처·브라우저/PDF 포커스에서의 전역 단축키 종합 시험은 별도다. Apple Silicon macOS 15 이상 개발 빌드이며 Apple 공증은 포함하지 않는다.
